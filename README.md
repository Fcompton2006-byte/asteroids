start key: source .venv/bin/activate

To start the game press the up arrow key to see "uv run main.py" then press enter

Move:
W: Foward
A: Turn counter clock-wise
S: Turn clock-wise
D: Backwards
Left Shift: Boost

Weapons: All weapons can be held. Each weapon also has a different cool down
Space: Machine gun
Numbpad 8: Shotgun
Numbpad 5: Boom
